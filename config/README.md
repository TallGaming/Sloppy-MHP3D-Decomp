# Configuration records

These JSON files primarily preserve historical diagnostic inputs and pins.
They are not a selected game toolchain or a portable build configuration.

Private game/tool/evidence files are deliberately absent. Personal environment
paths were replaced where needed; original source versus public-copy hashes are
listed in docs/publication/SOURCE_EXPORT.json. Other hashes remain historical
observations and must not be interpreted as fresh verification of an adapted
public file.

Use tools/repro/README.md for the self-contained public diagnostic entry point.
The reference identity in reference.json remains the selected PSP version;
the corresponding game image/ELF is not distributed.
