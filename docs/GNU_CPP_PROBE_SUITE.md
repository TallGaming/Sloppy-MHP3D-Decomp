fixed GNU C++/O2 profile. **Each profile reproduces exactly one original
interval: `probe_08826448`, the byte-copy/advance probe.** GCC4.3.5 supplies no
additional exact interval over the old GNU backend in this suite.

signature pairs, then reviewed the actual invented naming objects. Exact

type suffix; no target object, signature or symbol table is edited. The separate
naming/probe freezes precede the respective compilations. Ordinary return types
are not encoded in these names, so source-signature review remains necessary.

from3AA. Only then are the old/new complete fourteen-probe translation units
compiled. The old GNU C++ probe objects are a **new repeat baseline**, not
historical C/cc1 controls. Both target objects and raw assembly repeat exactly.
