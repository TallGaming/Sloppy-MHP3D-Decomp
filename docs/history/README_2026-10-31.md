## Inspect local inputs

Python 3.10 or newer is sufficient for the read-only inspector:

```powershell
python scripts/inspect_input.py "D:\path\to\game.iso" --out evidence\candidate.json
python scripts/inspect_input.py "D:\path\to\ULJM05800QST" --out evidence\quests.json
```

The inspector hashes the input and reads ISO9660 directory records and PARAM.SFO
metadata. It does not decrypt, modify, extract, or accept a baseline. Evidence
files describe observed inputs; they do not prove that an image is clean.

Run the inspector's synthetic format and error tests with
`python -m unittest discover -s tests -v`. These are separate from the future
build gate and its required 18 negative checks.
