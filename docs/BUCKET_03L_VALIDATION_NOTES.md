## Meaningful tooling controls

The twelve new tests use invented objects and a fully pinned temporary copy of
the existing archive/language/family fixture graph. Inherited verification is
real; only this runner's compiler call is mocked. No original game bytes appear
in the fixtures. Existing parser/comparator tests remain unchanged.

The new controls cover:

- All eleven fixed cases and exact commands, one complete member per successful
  case, two trials with twenty-two fresh paths, and deterministic reports.
- Nonzero return, warning, timeout, missing/malformed output, wrong member,
  extra function and unsupported code relocation at early, middle and late
  noncontrol cases. Each failed case remains visible without an exact count
  or partial comparison, while the other ten cases remain available.
- Fatal build 219 byte/metadata/failure drift and incorrect historical
  source/profile/reference bindings.
- Actual word differences for equal-size bodies and an untrimmed longer member
  sharing the target prefix. A missing comparison retains nulls rather than
  becoming a claimed improvement or zero score.
- Fixed case count/order, flags, trial/source-attempt counts, archive/catalogue
  identity, inherited source/target/naming/tool/native pins, mutations during
  compilation, report aliases and conflicting-report preservation.
- Later compilation replacing an earlier valid object or a retained partial
  object from a nonzero return or raised timeout. Every emitted object is
  checked again before publishing.
