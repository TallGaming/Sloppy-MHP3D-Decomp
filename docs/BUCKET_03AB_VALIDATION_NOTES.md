# Bucket 3AB independent validation

## Scope and review criteria

This bucket uses the unchanged complete fourteen-probe translation unit under
one fixed C++/O2 profile per verified GNU frontend. Stage A first observes the
existing invented fourteen-signature fixture. Only after independent review and
a separate mapping freeze may original diagnostic intervals be compared.

The exact Itanium `_Z` prefix, decimal identifier byte length and complete
synthetic identifier must match before replacing that identifier component.
The observed type suffix must remain unchanged and nonempty. Pair order and
signature categories must bind to the existing naming spec. All fourteen
symbols must form a unique complete set; extra, missing, duplicate or swapped
associations reject the mapping. No ELF symbol record is rewritten.

Both complete static-C++ historical objects must reproduce before either broad
probe configuration in each Stage B trial. A configuration requires all fourteen
complete functions and the unchanged strict comparator. Unsupported code
relocations, malformed extents or any compile/assembler/decoder diagnostic cannot
produce a partial configuration score. The old GNU C++ broad object is a new
repeat baseline, distinct from historical C/cc1 outputs. Whole-repeat objects and
raw assembly are checked separately from per-function diagnostic byte equality.

No helper launches a compiler, assembler or decoder. The parked initializer,
source-attempt and matching-shape counters, original ownership uncertainty and
unlocked historical toolchain remain unchanged. Exact diagnostic intervals do
not count as game matches or a full build/gate result.
