# Bucket 3AA independent validation

## Stage A: exact pre-execution review

Preserve 3Z's failed/unscored trials. This new stage reassembles only its exact
retained invented static-C++ .s, comparing the unchanged baseline with one new
assembler ABI declaration, -msingle-float. The choice follows the frontend's
preexisting enabled-single/disabled-double target help and emitted attribute4,2,
not any game-byte score. No compiler, game source, target or edited directive is
involved. This is neither warning suppression nor per-function compiler tuning.

Real inherited verification checks the old 3Z freeze, source/frontend/runtime/
host/tool and retained partial/assembly/help identities. Before freezing, the
helper identifies an overly broad target-help guard: an enabled option elsewhere
could satisfy it even if single-float were disabled. The primary binds enabled
single-float and disabled double-float to their exact option lines. Linked build
roots are also explicitly rejected before fresh output creation.

The baseline is a negative control: it must reproduce exactly the expected
warning and can never count as a clean pipeline. The consistent case requires
zero exit, empty diagnostics and complete object equality to the pinned original
partial artifact. Missing or changed code/data/symbol/relocation bytes reject the
case; no masks, rewritten attributes or instruction comparison substitutes are
allowed. Raw input/output snapshots and inherited pins are rechecked after each
case. A later Stage B needs its own approvals and freeze.
