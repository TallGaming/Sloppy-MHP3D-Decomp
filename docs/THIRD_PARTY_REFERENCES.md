# Third-party references

These projects informed research or are external tool dependencies. They are not
bundled tool/SDK distributions or evidence that their settings belong to MHP3.
Consult the corresponding upstream repository for its license and version.

- [MHP2G matching decompilation](https://github.com/tclamb/mhp2g-decomp): related
  engine/build-pipeline and source-context comparisons.
- [PSPDEV / PSPSDK](https://github.com/pspdev/pspsdk): PSP format/API definitions.
- [PPSSPP](https://github.com/hrydgard/ppsspp) and
  [JPCSP](https://github.com/jpcsp/jpcsp): source-backed module-format references.
- [pspdecrypt](https://github.com/John-K/pspdecrypt): separately obtained local
  reference-preparation helper; its implementation and metadata are not bundled.
- [MHTools](https://github.com/codestation/mhtools): archive-algorithm references.
- [wibo](https://github.com/decompals/wibo): separately obtained host runner.
- [decomp.me](https://github.com/decompme/decomp.me): local workbench research;
  no private instance state or hosted public demo is included.
- [Ghidra](https://github.com/NationalSecurityAgency/ghidra): external static
  analysis tool; only our export script is included.
- [Detect It Easy](https://github.com/horsicq/Detect-It-Easy): partial signature
  rule review; no scanner execution is claimed.

Historical reviews retain exact upstream commits where available. Private PS1
retrospectives/workflow documents were supplied as references; they are not
redistributed and their successful results are not this project's results.
